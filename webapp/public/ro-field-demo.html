This page demonstrates a two-input sampled field or exact 2D cell complex using the strict bne-ro-field/v1.0.0 artifact. Invalid samples, singular strata, and uncomputed regions remain visible as gaps rather than being converted to zeros.

The request and response are inline and bounded. This page does not persist results, does not run a full Atlas campaign, and does not claim exhaustive coverage beyond the declared work budget. Higher-dimensional fields require an explicit server-generated 2D slice; the viewer never invents a projection.
