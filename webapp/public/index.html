A single canvas from reaction sketch to regime geometry.

Biocircuits Explorer turns binding-network hypotheses into inspectable behavior landscapes. Build reactions, enumerate regimes, visualize responses, and search atlases — all in the same workspace.

Capabilities, one at a time.

Each capability is a live node on the canvas. Wire them up, run, and watch the workspace update in place.

01 · ROP polyhedron

Exact polyhedron geometry for every regime.

Enumerate vertices, edges, and faces of the Reaction Order Polyhedron. Rotate, inspect supports, and read dominant orders directly off the geometry.

  • Exact vertex and face enumeration
  • Interactive 3D rotation and inspection
  • Dominant order labels per vertex

02 · SISO behaviors

Trace single-input, single-output paths across regimes.

Walk SISO paths between regimes, compare asymptotic and singular families, and see how design choices move the response signature across the polyhedron.

  • SISO path traversal with regime overlays
  • Asymptotic and singular family comparison
  • Behavior signatures aligned to inputs and outputs

03 · Parameter scan

Sweep parameters and watch the response surface respond.

Run 1D and 2D parameter scans with live plotting. Pin a crosshair, drag across the grid, and the result node updates without leaving the canvas.

  • 1D and 2D scans with live plotting
  • Interactive crosshair and value readout
  • Results feed straight back into downstream nodes

04 · ROP cloud

Sample the polyhedron as a response point cloud.

Generate ROP point clouds to see how sampled regions of parameter space land on the polyhedron. Useful for spotting robust regimes before committing to experiments.

  • Stochastic sampling across parameter space
  • Point cloud overlaid on polyhedron geometry
  • Filter by region, regime, or behavior family

05 · More on the canvas

Atlas search, workspace management, and more.

Atlas-backed inverse design, workspace JSON import and export, project drawer, theming, and the rest of the canvas-level features that keep an analysis session moving.

  • Atlas libraries with SQLite merge and reuse
  • Workspace save, restore, and share
  • Project drawer and native shell integration

Move from hypothesis to evidence in four steps.

The same path works in the browser or the native macOS shell. Workspaces and atlas libraries stay portable between them.

  1. 01

    Sketch the binding network

    Start with reactions, constants, totals, and observable species in the browser or native shell.

  2. 02

    Build the symbolic model

    Assemble model structure, enumerate regimes, and prepare vertices, graphs, and SISO paths for analysis.

  3. 03

    Explore transitions

    Trace SISO paths, compare behavior families, and inspect response surfaces for robust design signals.

  4. 04

    Save, reuse, publish

    Keep workspace JSON, project drawers, atlas libraries, and SQLite stores aligned across web and macOS.
