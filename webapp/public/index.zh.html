五个原语。一个设计曲面。

每个原语都是画布上的一个节点。把它们连起来、跑一次、工作空间就地刷新 —— 这正是硬件设计师对 EDA 期望的迭代回路。

01 · 响应曲面几何

回路能落到的每一个 regime，组成一个多面体。

精确枚举反应级数多面体（ROP）的顶点、棱、面。旋转几何、检查 support、直接从几何上读出主导级数 —— 就像 EDA 工具展示时序裕度，而不是只给你一个“过 / 不过”。

  • 顶点与面的精确枚举
  • 3D 旋转与交互式检查
  • 每个顶点带主导级数标签

02 · 输入输出验证

回路在不同 regime 之间到底会怎么走。

跟踪你选定的输入/输出对在参数变化时所走的 SISO 路径，把渐近族与奇异族并排比较。在湿实验跑一轮之前，就先看清回路真正会停在哪些 regime。

  • 带 regime 叠加的 SISO 路径遍历
  • 渐近 vs. 奇异行为族对照
  • 钉住输入输出的行为签名

03 · 容差分析

在实验台决定之前，先扫一遍参数。

1D / 2D 参数扫描带实时绘图。钉住十字光标、在网格上拖动，结果节点不离开画布也会就地更新。这是板级设计师常对元器件方差跑的容差回路 —— 只不过这里的方差来自生物本身。

  • 1D / 2D 扫描，实时绘图
  • 交互十字光标与数值读取
  • 结果直接回流到下游节点

04 · 噪声下的鲁棒性

哪些 regime 在参数云里活了下来？

对参数空间做随机采样，再把云点叠到多面体上。鲁棒 regime 会以密集簇出现，脆弱的则散落在外围。在细胞间方差下，选那个能落到鲁棒 regime 的设计 —— 而不是仅仅在原理图上“看起来干净”的那个。

  • 跨参数空间的随机采样
  • 云点叠加到多面体几何上
  • 按体积分数给每个 regime 打鲁棒性分

05 · 逆向设计、AI Import、远程计算

设计库、AI Agent，以及云端集群。

Atlas 逆向设计在网络库里搜出能实现目标行为的候选；AI Import 一键把论文 / Notebook 翻译成已填好参数的分析链；Cloud Compute 把重 Atlas 构建甩到 AWS Batch；工作空间始终保持可版本化的 JSON。

  • 支持 motif、见证、鲁棒性等多种查询的逆向设计
  • AI Import 支持 Claude / DeepSeek（Key 全程留在你的浏览器）
  • Cloud Compute 配套 Cognito 账户与按用户配额

从假设到一个可以放上汇报的设计。

四步走同一条路 —— 不论在浏览器、原生 macOS 应用，还是经典表单界面。工作空间与 Atlas 库在三者之间始终可移植。

  1. 01

    勾勒结合网络

    录入反应、Kd 值、守恒总量与可观测物种 —— 或者让 AI Import 一遍把它们从论文里抽出来。

  2. 02

    编译符号模型

    model-builder 把草图编译成矩阵 N 与 L，枚举 regime 顶点，并交还一个会被所有下游节点复用的 session。

  3. 03

    验证响应几何

    走 SISO 路径、跑参数扫描、采样参数云、检索 Atlas。在你下决心做实验之前，先把回路能到达的每个 regime 都演练一遍。

  4. 04

    交付设计

    导出可移植 JSON 工作空间、交接 SQLite Atlas 库，在合作者的机器 —— 或 CI worker 上 —— 复现同一份分析。
